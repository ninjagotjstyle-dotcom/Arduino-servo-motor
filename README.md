
# Arduino-servo-motor
This is a code thing for making an arduino servo motor on D9, 5V
To make this Servo setup, Have minimum of 3 jumper wires, but you can add more for complexity, 1 servo, and an Arduino uno R3. This code makes the servo spin then spin back indefinitely. To stop servo, press white button on Arduino Then quickly remove a wire to break the circuit.
